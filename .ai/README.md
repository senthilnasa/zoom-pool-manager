# AI Agent Workspaces & Development Context

This folder contains internal development guidelines, instructions, task lists, and handoff documentation utilized by AI coding assistants (such as Antigravity, Claude, and Gemini) during project development cycles.

## Contents
- **`CLAUDE.md`**: Master agent operating instructions, verification rules, architectural standards, and constraints.
- **`TASK.md`**: Detailed development roadmap, milestone checklist, progress history, and technical deliverables.
- **`HANDOFF.md`**: State tracking, session notes, and operational logs between development iterations.

These files are organized here to maintain a clean, standardized, and professional root directory structure according to modern open-source conventions.
