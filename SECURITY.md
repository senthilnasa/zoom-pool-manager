# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Zoom Pool Manager (ZPM), please report it responsibly rather than opening a public issue on GitHub.

### Reporting Channels
- **Author:** Senthil Nasa
- **GitHub:** [https://github.com/senthilnasa](https://github.com/senthilnasa)
- **Repository Security Advisory:** Please use the "Report a vulnerability" tab under GitHub Security on [github.com/senthilnasa/zoom-pool-manager](https://github.com/senthilnasa/zoom-pool-manager/security/advisories/new).

Please provide:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Impact assessment.

We take security issues seriously and will respond promptly to investigate and release coordinated security patches.
