# Meeting Templates

Meeting Templates (`/app/templates`) streamline repetitive scheduling by pre-configuring settings, buffer times, participant capacities, and security profiles.

---

## 📋 Default System Templates

ZPM comes pre-seeded with canonical institutional templates:
1. **Academic Lecture / Class**:
   - Duration: 60-90 minutes
   - Host Key reveal: 15 minutes prior
   - Automatic cloud recording enabled
   - Waiting room active for non-enrolled guests
2. **Faculty Committee / Senate**:
   - High-security profile with encrypted passcodes
   - AI Companion disabled for confidentiality
   - Attendance tracking enabled
3. **Open Office Hours**:
   - Minimal buffer time
   - Waiting room mandatory to allow private 1-on-1 consultations
4. **Large-Scale Webinar**:
   - Assigned to Webinar Pool
   - Q&A module active, attendee microphones muted on entry

---

## 🛠️ Custom Templates

Administrators can create custom templates tailored to specific faculties, programs, or organizational units. Templates can be locked so users cannot alter mandatory compliance settings during booking.
