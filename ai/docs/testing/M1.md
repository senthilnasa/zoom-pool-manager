## 2. Manual Verification Walkthrough

### Step 1: Web Installer Pre-Flight Checks
1. Access `http://localhost:8000/` or `http://localhost:8000/installer` in a browser.
2. Confirm the Welcome screen renders with project tagline and setup steps.
3. Click "Begin Pre-Flight Check" to navigate to `/installer/requirements`.
4. Verify that:
   - PHP version displays `8.3.x` with a green checkmark.
   - Required extensions (`pdo_mysql`, `bcmath`, `mbstring`, `xml`, `gmp`, `intl`, `curl`, `zip`) report loaded.
   - Storage directories (`storage/framework`, `storage/logs`, `bootstrap/cache`) report writable.

### Step 2: Database Configuration & Connection Test
1. Proceed to `/installer/database`.
2. Enter database connection parameters:
   - Host: `db` (or `127.0.0.1`)
   - Port: `3306`
   - Database: `zpm`
   - Username: `zpm`
   - Password: `secret`
3. Click "Test Connection".
4. Confirm live AJAX feedback reports `MariaDB/MySQL detected: Connection established successfully.`
5. Click "Migrate & Continue". Verify migrations execute without error.

### Step 3: First Super Administrator & Mandatory TOTP Enrollment
1. Navigate to `/installer/admin`.
2. Enter Administrator Name and Email.
3. Confirm that:
   - An SVG QR code is rendered on screen.
   - A 32-character base32 secret is shown.
   - 10 single-use emergency recovery codes are displayed.
4. Scan the QR code in Google Authenticator or 1Password.
5. Enter the 6-digit TOTP code and submit.
6. Verify that an invalid code is rejected with an error message, and a valid code proceeds.

### Step 4: Organization Profile & Timezone
1. Set Organization Name (e.g., `Reference University`).
2. Select Timezone (`Asia/Kolkata`).
3. Set Default Meeting Buffer (e.g., `10` minutes; verify validation blocks values < 10 or > 60).
4. Click "Finalize Installation".

### Step 5: Lock File & Security Enforcement
1. Confirm the completion screen shows `Locked (storage/installed.lock) ✓`.
2. Attempt to navigate back to `/installer`. Verify HTTP 403 Forbidden is returned.
3. Test CLI unlock command:
   ```bash
   php artisan zpm:installer:unlock --force
   ```
4. Confirm the lock is removed and `/installer` becomes accessible again.

### Step 6: Health Endpoint
1. Visit `http://localhost:8000/admin/health`.
2. Confirm valid JSON payload indicating status `healthy`, database driver, and application version.
